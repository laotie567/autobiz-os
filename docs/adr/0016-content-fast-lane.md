# 内容快产线：周计划 → 批量定档 → 排产 → 初稿 + 体检 → 审改 → 创作包（S2）

2026-10-16。触发：周发布目标 50 条（8 种形态，真人口播每天 2 条，数字人暂缓），而内容域只有"选题 → 登记发布"，
写稿、排期、审改全在系统外；旧飞书管线还出现过 AI 替本人编履历（"从 0 做到 3.5 万粉"，实际刚起号）。
用户拍板的流程：系统出初稿 → 本人审 → 系统按意见改好；视频在小云雀出、图在豆包出，系统负责脚本 / 分镜 / 剧情大纲。

## 决定

- **新对象 `content_piece`（内容件）**：一个选题拆成多个内容件，每件一种形态 + 一个默认平台。
  状态机 `planned → in_review | check_failed → approved | changes_requested → in_review … → produced → published`，
  生命周期字段（状态 / 版本 / 稿件 / 体检 / 历史）由流程行动维护。
- **唯一的人工闸门仍是选题定档**（ADR-0004），但改为**批量**：`finalize_topics` 一个审批码定一周的选题。
  审稿通过不设 PIN——每周 50 次 PIN 不可持续；内容风险由"定档闸门 + 代码体检 + 只能引用已确认知识"三层兜底。
- **排产是代码，不是模型**：`schedule_pieces` 按 `profile.goals.format_mix` 分配名额，优先选题的建议形态、
  同一选题尽量不重复形态、负载均衡；真人口播按 `daily_live_talk` 每天固定条数，其余按日均衡。
- **模型只写稿**：可引用知识（已确认）编号交给模型，只能引用编号；来源文档只作背景，不得说成本人经历。
  形态写法各一份提示词（`prompts/format_*.v1.md`），品牌约束（语气 / 禁说词 / 平台风格 / IP 形象）从 profile.brand 注入。
- **代码体检**（确定性，起草和改稿后都跑）：品牌禁说词、绝对化用语、**无依据的自述**、篇幅区间、私信关键词、
  出口检查（全量客户名与个人信息）。不过 → 带着问题自动重写一次 → 仍不过标 `check_failed`，不进审稿队列。
- **个人可宣称事实台账** `$AUTOBIZ_HOME/config/claims.yaml`：第一人称 + 成绩数字 / 经历动词的句子，
  必须命中台账某条的关键词且数字一致。视频事实块（ADR-0014）的"台账 + 闸门"思路平移到个人品牌。
- **产物是创作包文本**：真人口播出双栏稿 + 提词器纯台词；动效 / 科普 / 图文视频出可整段粘贴进小云雀的指令段
  （科普另出剧本段与事实核对清单）；图文出逐张卡片与生图提示词；长文出正文 + 三平台标题。
  小云雀是否严格遵循给定旁白需用户实测后再微调模板。
- **数字人口播预留**：形态与提示词保留，`profile.avatar.enabled=false` 时起草直接拒绝，配比 0 时不排产。

## Consequences

- 每周约 50 次起草 + 若干改稿走 deepseek-v4-pro，单稿约几分钱，计入 llm_usage 与每日预算。
- 审稿效率决定产能：`review_queue` 只给要点，Agent 每次讲 3–5 条；若仍嫌慢，下一步把审稿队列投影到飞书多维表格。
- 台账为空时任何"我"的经历都会被拦——这是有意的：宁可少说，不可编。
- 发布登记改在内容件上（`publish_piece`，可多平台各登记一次），旧的 `mark_published` 保留给不走快产线的单条内容。

# 0 号场景定为内容获客流水线

候选场景有三个：个人学习平台（自我信息消化）、客户项目交付管理、内容获客流水线。选择内容获客流水线：获客是培训 / 陪跑 / 定制开发三条业务线的共同前提，且该场景打通后本身就是可售卖的"AI 做 IP"最佳实践案例与课程素材。

范围边界：信息收录 → 内容生产 → 多平台发布 → 发布数据回收。私信 / 社群中的线索转化与成交管理不在 0 号场景内，留作 1 号场景。

## Considered Options

- 个人学习平台：自用价值高，但不直接产生现金流；其"信息收录"部分被内容流水线覆盖。
- 客户项目交付管理：当前客户量小，管理复杂度尚不需要系统支撑。

# 知识域是系统的复利中心，首个可每日使用的切片为"知识域 + AI 问答"

修正 ADR-0002 的方向。0 号场景把系统建成了一条内容流水线，"个人学习平台"被排除在外。评审时确认的四个问题：太像流水线、学习成长未覆盖、AI 不懂业务、停在文档没落地。

决定：本体以知识域为中心（行业 → 痛点 → 案例 / 方法 / 工具 / 概念，以及我的洞见、实操记录、掌握度），市场域（内容获客）、客户域、交付域都引用知识对象。首个切片在 1-2 周内交付可每日使用的能力：信息源自动入库并抽取成知识对象，在 Claude 中通过 MCP 直接查询、推理与记录。

## Consequences

- 0 号场景的内容流水线不废弃，迁移到新底座后改为从知识对象取料（"素材"更名为"来源文档"）。
- AI 抽取对象"全自动入库 + 对外使用前确认"：entity 默认 verified=false，被课件 / 方案 / 发布内容引用前必须经 verify_object 闸门。
- 信息源分两批：1a 现有 X 剪藏 / 素材库 + 对话式随手记；1b 社群笔记 / 博主内容 + 飞书文档 / 妙记。
- 学习成长能力纳入切片 1：掌握度追踪、实操记录、学习缺口推荐。

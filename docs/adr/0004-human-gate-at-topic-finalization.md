# 唯一人工闸门设在选题定档，其余节点全自动

九个节点中只有"选题定档"必须人工执行；收录、打分、母版与变体生成、体检审核均自动。理由：选题是杠杆最高、成本最低的把关点——定错选题浪费整条流水线，而后续环节的质量问题可用自动体检规则拦截。

## Consequences

- Action 注册表按"自动 / 需人工"二分权限；未来新招助理的接管范围以此表为准。
- 数字资产的"审核"从人工审批改为自动体检规则（全绿自动通过，红灯转人工）。
- 发布动作的执行受平台限制，当前模式为：人在外部平台 App 发布，回系统标记已发布并手填回填数据。接入第三方发布工具是后续可选项，不影响本体结构。
- 变体生成开发顺序：抖音 / 视频号短视频优先，小红书图文排后。仅为排期顺序，不影响本体结构。

# 视频生产纳入本体：8 步法落成 action + 规则手册

2026-10-06。触发事件：纪录片《四渡赤水》三版产物（2D 地图动效 / Three.js 3D / Blender 光追）暴露出
"方法在库里、实践在裸奔"——本体里躺着《Opus 5.5 动效视频指南》与它抽出的 8 步法（`source_doc_051774fb63`），
但这条片子跳掉了其中最关键的三步（写规则手册、找参考写 style_guide、拼联系表做审美自查），
结果精准踩中"深色渐变 + 正中大标题 + 左上角小标签"的 AI 味三连；光追版成片的标题甚至是镜像的（字面转反了）
且一直没人发现。用户指示：把 8 步法写成正式生产流程文档并为系统加对应行动。

> 注：ADR-0011 曾定"连续使用两周前不新增业务域或功能"。本次是用户明确的指令性例外，
> 且只增不改——不动既有 20 类对象与既有行动。

决定：
- **规则手册一律叫 `AGENTS.md`，不叫 `CLAUDE.md`**。生产期跑国内模型（豆包 / DeepSeek / GLM / Kimi），
  `AGENTS.md` 是跨厂商通用约定，`CLAUDE.md` 只是 Anthropic 一家的私有名。一份文件，所有模型共用。
  模板落在 `docs/video-production/AGENTS.md`，立项时复制到项目根。
- **8 步法落成本体的两个 action**（新增对象类型 `video_project`，挂在 `market` 域——内容获客是它的主要出口）：
  - `start_video_production`：建项目文件夹、复制规则手册、建对象、回 8 步清单。
  - `check_video_production`：按 8 步**查产物文件在不在**（`AGENTS.md` → `style_guide.md` → `BRIEF.md`+`shotlist.md`
    → `beats.json` → `check/contact-sheet.jpg` → `renders/*.mp4`），顺序推进、幂等、自动把进度写回 `status`。
- **闸门是文件，不是自述**。视频是最容易被"看起来做完了"骗过去的活：画面能播不等于好看，机械检查全绿不等于能交付。
  所以判定交给文件系统（代码判定对错，对齐 `model-quality.md` 原则 1）。`check_video_production` 标 `direct`
  （只读盘 + 同步状态，幂等无副作用），跳过预览；终验仍是人工闸门。
- **三版产物收敛**：放弃 3D 光追路线（Cycles 720p/12s 用 59 分钟，全片要 15 小时以上；地形是程序化噪声，
  无史实地图信息量），归档到 `纪录片_四渡赤水/_archived_3d/` 并写明废弃原因与可复用部分。
  生产路线收敛为 2D 地图动效一条。

## Consequences

- 视频项目现在有了可机器检查的进度，但**系统不生成视频**——生成仍在项目文件夹里由工具链完成，系统只查产物。
  这是刻意的边界：生成能力随模型迭代快速贬值，8 步法（方法）才是越沉淀越值钱的资产。
- 8 步法的"审美自查"（第 7 步）只能靠联系表 + 人/模型看图，路径检查无法替代。文件存在 ≠ 片子好看，
  这一点不要被绿灯误导。
- `video_project.dir` 必须填绝对路径；体检全靠它。填错会直接报"项目文件夹不存在"。
- 若日后视频产量大到需要独立业务域，再把这个类型迁出 `market`（本体即代码，无数据库迁移成本）。

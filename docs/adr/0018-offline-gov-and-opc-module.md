# 线下政企项目能力 + OPC 基地招商私有模块（S4）

2026-10-16。用户拍板：区级政府、国有平台公司这类政企客户归**线下项目线**（offline）；
合伙公司代运营智算云 OPC 基地的招商归**合伙业务线**（partner）；两条线都不计入线上业务的月收入目标。

## 决定

- **拍板口径台账 `decision`**（核心能力，随发布）：客户拍板的口径原话 + 适用范围 + 拍板人 + 禁用说法；`record_decision`
  直接写入，口径变了用 `replaces` 替代旧口径（留痕）。方案生成 / 改稿把该客户全部有效口径作为硬约束注入提示词，
  禁用说法出现在模型输出里即校验不合格、自动重写——某政企项目多轮迭代里反复手工纠正的口径问题，从此由系统兜住。
- **计价方式**：`pricing` = 按产品标价（原逻辑）/ 人天计价（`man_days` 角色 × 人天 × 单价）/ 一事一议总价（`total`）。
  金额仍然只由代码计算；人天参数在调模型前校验。改稿沿用上一版的计价方式、签约主体与采购阶段。
- **签约主体与采购阶段**：方案增加 `entity`（落款）与 `procurement_stage`（意向 → 立项 → 可研 → 报批 → 采购 → 签约），售前看板显示。
  客户类型增加国企 / 平台公司、政府 / 事业单位；会议 / 线下渠道新客户默认 offline。
- **OPC 基地招商是私有模块**（`ontology/opc.yaml` + `autobiz/opc.py`，与视频板块同样不随开源发布）：
  空间（工位 / 办公室 / 会议室）、入驻协议、招商活动；`add_spaces` 批量登记、`reserve_space` / `release_space`、
  `sign_residency`（闸门，可一次签多个空间，企业自动标入驻企业 + partner）、`end_residency`、`log_event`（关联线索）；
  查询 `occupancy`（出租率按个数 / 面积、到期入驻、过期预留）与 `opc_pipeline`；日报增加 OPC 一行。
- 决策链（stakeholder）与 Word / PPT 生成本轮不做：四件套继续用各项目已验证的生成脚本，产物链接回填。

## Consequences

- 空间清单需要按真实情况登记一次（编号规则、一期 / 二期、工位 / 办公室数量与面积），系统不预置任何数字。
- 口径的质量取决于是否当场记下；`AGENTS.md` 要求 Agent 听到"他们定了 / 这个不能说"就立刻 `record_decision`。
- 发布仓库不含 OPC 模块；核心里的 `org_type` 不含"入驻企业"，该值由私有 `opc.yaml` 以 extend 方式追加。

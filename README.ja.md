## これは何か

一人＋AI エージェントでコンサル／サービスビジネスを運営するためのフルバックオフィス。Notion のテンプレートではなく、**ビジネスルールエンジン付きのデータベースシステム**です：

- **オントロジーが唯一の正**——顧客・ペインポイント・事例・製品・入金はすべてオントロジー上のオブジェクト。`ontology/*.yaml` に一箇所で定義し、ビュー・アクション・AI ツールはすべてそこからコンパイルされる
- **Action エンジンが唯一の書き込み経路**——すべての書き込みは事前にプレビューされ、監査ログに残る。**人工ゲートはエンジンが強制**——AI 自己判断で商談成立やプロジェクト完了は確定できない。承認コードは必ず本人がターミナルで入力する
- **モデルは書き、コードが探して計算する**——AI が起草する提案書はシステムが与えた「確認済みナレッジ」しか引用できず、金額はすべてコードが計算——**捏造はプロンプトではなく仕組みで防ぐ**
- **引用グラウンディング**——AI が抽出したナレッジは原文の引用句が必須。虚構の内容は決定論的に破棄される

```
$ autobiz q overview
$ autobiz req "顧客名" "一度買って帰ると二度と来てくれない" wechat
$ autobiz act analyze_requirement '{"target":"org_xxx"}'
$ autobiz approve K7Q2PX        ← 人工ゲート：本人がターミナルで承認
```

## 15 分で始める

```bash
git clone https://github.com/laotie567/autobiz-os.git && cd autobiz-os
bash scripts/install.sh         # Docker があれば OK
```

## 設計思想（なぜこういう形か）

- **人工ゲートはエンジンが強制**——AI アシスタントはデフォルトで最小権限。プレビュー規律、承認コード、ライフサイクルフィールド保護——信——信頼しつつ検証する
- **カーネル／ワークスペース分離**——パーソナライズ（プロファイル、業界フィールド、プロンプト調整）はすべてワークスペース側。カーネルのアップグレードと衝突しない
- **拡張可能なオントロジー**——`extend: true` オーバーレイで自分の業界フィールドを追加。カーネルコードは 1 行も変えない
- プライバシーとデータフローは [PRIVACY.md](PRIVACY.md)、セキュリティモデルは [SECURITY.md](SECURITY.md)
